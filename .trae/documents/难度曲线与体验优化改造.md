# 难度曲线与体验优化改造方案 v2

## Context

局外养成已上线但战斗偏易、阵营同质、货币混乱、缺动画反馈。本改造在原方向基础上**新增两个系统**以增加策略深度：①阵营特性局外养成升级树（初始削弱、用精魄升级解锁更强特性）；②局内减益环境（每关有环境 modifier 增加构筑/输出难度，倒逼养成投入）。其余四项（难度曲线、动画、双货币、阵营锁定卡池）保持。

## 1. 难度曲线（data.js / game.js / meta.js / core.js）

- 玩家弱化：`getBattlePlayerStats`（meta.js L113）基础 maxHp `900→600`、attack `120→90`、critRate `0.05→0.03`、handLimit `6→5`、theurgyMax `3→2`。`getStatDisplay`（L101）同步文案。
- 输出压缩：`POWER_MULTIPLIER`（data.js L42）`{1:0.5,2:1.0,3:1.8,4:2.8,5:4.0}` → `{1:0.4,2:0.8,3:1.4,4:2.2,5:3.2}`。圣杯加成 `1+0.5*cupStack → 1+0.4*cupStack`（core.js L103）。
- 敌方强化：ENEMIES（data.js L537）全体 HP ×1.3、attack ×1.25；shadow_priest/reaper/stone_golem 加恢复技能。
- 敌方伤害：`calcEnemyDamage`（game.js L282）倍率表 `{1:0.6,2:1.2,3:2.0,4:3.2,5:4.5}`；DAMAGE_REDUCE `0.85→0.80`；DEF_UP `0.7→0.65`。
- 经济压缩：`startTurn`（game.js L203）收入 `100+turn*20 → 80+turn*15`；抽牌 `min(5,2+deckLevel) → min(4,1+deckLevel)`；抽牌费 50→60；升级费表 ×1.2。

## 2. 多波次关卡（data.js STAGES + game.js）

- STAGES 每项加 `waves` 递增式：CH.1=2波、CH.2=2波、CH.3=3波、CH.4=3波、BOSS=4波（见 v1 表）。
- game.js 加 `this.waveIndex`；`startStage` 读 `stage.waves[0]`；`checkBattleEnd`（L580）当前波全死 → `waveIndex++` 生成下一波（玩家不回血，清构筑槽/倒地，emit `waveStart`），最后一波清空才 `battleEnd(true)`。战败任一波立即结束。

## 3. 战斗动画（css/style.css + ui.js + game.js emit）

- 新增 keyframes：`cardEnter`(scale-in)、`cardPlay`(上飘消散)、`enemyLunge`(突进)、`elementFlash`(属性色屏闪)、`healPulse`(HP 绿脉动)、`floatUp2`(染色浮动数字)。
- 触发点：`renderHand`(ui.js L231) 新卡 `.card-enter`；`onHandCardDblClick`(L280) 打出 `.card-played`；`renderComposeSlots`(L168) 入槽 `.card-enter`；`enemyTurn`(game.js L254) 攻击前 `emit("enemyAttack",{enemy,skill})` → ui 加 `.enemy-attacking`+`.el-flash-{element}`；`onEnemyHit` 浮动数字按 affinity/element 染色；`onPlayerHeal` HP 条 `.heal-pulse`。

## 4. 双货币体系（meta.js / game.js / hub.js / ui.js / data.js）

- **Persona精魄 ◈** = `meta.money`（字段名不变），持久，用于商店/合体/阵营升级。UI 标签 ¥→◈。
- **局内资金 ¥** = `player.money`，每局固定起手 120（game.js L56 `money:(meta&&meta.money)||120` → `money:120`），仅战斗内抽牌/升级，不持久。
- `battleEnd`（L588）删 `player.money += reward`；保留 `meta.money += reward`（→ 精魄）。日志「获得 N 精魄」。
- SHOP_ITEMS 金币包改名「精魄包」，type `GOLD` 仍 `meta.money += amount`。hub.js 文案 ¥→◈（L53/367/256/261）。index.html hub header ¥→◈（L29），战斗 status-bar ¥ 不变（L65）。

## 5. 阵营锁定卡池（game.js buildDeck L84 + hub.js renderArcana）

- `buildDeck`：`pool = this.arcana.persona_pool.filter(k => !meta || meta.isUnlocked(k))`；空则回退 STARTING_PERSONAS。仅本阵营已解锁人格面具入牌库。
- `hub.js renderArcana`（L330）：计算 `poolUnlocked = a.persona_pool.filter(k=>meta.isUnlocked(k)).length`；为 0 的阵营加 `.locked`、隐藏选择按钮、显示「未解锁人格面具」，不可选。

## 6. 【新增】阵营特性局外养成升级树（data.js ARCANA + meta.js + hub.js + game.js + core.js）

### 设计：初始削弱 + 3 级可升级
每个阵营特性分 Lv.1（削弱初始）/ Lv.2 / Lv.3（强化）。用精魄升级当前选中阵营。

### data.js ARCANA 改造
每项 `bonus` 文案改为数组 `bonusLevels: ["Lv.1 描述","Lv.2 描述","Lv.3 描述"]`，保留 `bonusKey`。例：
- FOOL `["首次构筑+1阶","首次2次构筑+1阶","所有构筑+1阶"]`
- MAGICIAN `["火焰+10%","火焰+20%且+1阶","火焰+30%且+1阶且范围转ALL"]`
- JUSTICE `["暴击+5%","暴击+10%且暴击回5%HP","暴击+15%且暴击回10%且无视抗性"]`
- STRENGTH `["攻击+5%","攻击+10%","攻击+15%"]`（替换原固定+20）
- TEMPERANCE `["减伤10%","减伤15%且回合回5%HP","减伤20%且回合回10%HP"]`
- DEATH `["击杀回15%HP","击杀回25%HP","击杀回25%且<30%血处决+50%"]`
- HERMIT `["多抽1张","多抽2张","多抽2张且可看牌顶"]`
- HIEROPHANT `["+¥30/回合","+¥60/回合","+¥80/回合且起手+¥100"]`
- 其余 11 阵营同理补 3 级文案。

### meta.js
- 新字段 `arcanaLevels = { FOOL:1, MAGICIAN:1, ... }`（load/save 加入）。
- `getArcanaLevel(id)` 返回 1-3。
- `upgradeArcana(arcanaId)`：cost = `level * 800` 精魄，扣 `meta.money`，`arcanaLevels[id]++`，save。Lv.3 满级拒绝。
- `getBattlePlayerStats` 与 game.js 各应用点改用「按当前阵营等级取效果」。

### hub.js
- 在「阵营选择」tab（renderArcana）卡片内显示当前等级 + 升级按钮 + 精魄费用，Lv.3 显示「已满级」。
- 新增 7th tab「阵营养成」可选（或合入 arcana tab），集中展示所有阵营升级进度。建议合入 arcana tab 减少改动。

### game.js / core.js 应用点按等级
- 引入 `arcanaLv = this.meta ? this.meta.getArcanaLevel(this.arcana.id) : 1`，switch 分级应用。
- `getEffectiveComposeSkill`（game.js L618）：FOOL/MAGICIAN/EMPEROR/CHARIOT/HANGED 的「力度+1阶」按等级启用。
- `calculateDamage`（core.js L88）/`applyDamageResult`（game.js L505）：MAGICIAN/EMPEROR/CHARIANT 伤害%、JUSTICE 暴击回血、DEATH 处决、FORTUNE 逆位加成按等级。
- `startTurn`（game.js L203）/`startStage`：HIEROPHANT 收入、HERMIT 抽牌、TEMPERANCE 回血、LOVERS 圣杯卡按等级。
- `getBattlePlayerStats`（meta.js L113）：STRENGTH/CRIT_UP/EXTRA_REVERSE 按等级数值。

## 7. 【新增】局内减益环境（data.js STAGES + game.js + ui.js + core.js）

### 数据
STAGES 每项加 `environment` 字段（每关不同，递增难度）：
- CH.1：`"POWER_MINUS_1"`（所有玩家技能力度-1阶，下限 SM）
- CH.2：`"COMPOSE_COST_UP"`（构筑需多1张牌，最低2张）
- CH.3：`"HEAL_HALVED"`（玩家恢复效果-50%）
- CH.4：`"ENEMY_ATK_UP"`（敌方攻击+25%）+ 上一条
- BOSS：`"CRIT_DOWN"`（玩家暴击率-50%）+ 上一条
BOSS 叠 3 层环境。可设计 `environment: ["POWER_MINUS_1"]` 数组支持叠加。

### game.js
- `startStage` 存 `this.environment = stage.environment || []`。
- 应用点：
  - 力度-1：`getEffectiveComposeSkill`/`composeSkill` 返回 power = max(1, power-1)（若 env 含 POWER_MINUS_1）。
  - 构筑多1张：`confirmCompose` 检查 `composeSlots.length < (environment含COMPOSE_COST_UP?2:1)` 拒绝。
  - 恢复减半：`healPlayer`（L304）/`executeSkill` HEAL 分支 amt *= 0.5。
  - 敌方攻击+：`calcEnemyDamage`（L282）base *= 1.25。
  - 暴击-：`calculateDamage`（core.js L105）critRate *= 0.5。

### ui.js
- status-bar（index.html）加环境徽章区：`render`（ui.js L91）显示 `g.environment` 列表为红色徽章 `⚠ 力度-1` 等。

## 验证

1. 起服务、清档：Hub 显精魄 ◈ 200，仅 FOOL 阵营可选（其余未解锁禁选）。
2. FOOL Lv.1 出战 CH.1：2 波、玩家 600/90、力度-1 环境生效（power 明显低）；通关得精魄。
3. 商店/阵营养成：用精魄把 FOOL 升到 Lv.3，再战确认「所有构筑+1阶」生效。
4. CH.2：COMPOSE_COST_UP 环境下 1 张牌构筑被拒、需 2 张。
5. BOSS 4 波叠 3 环境（力度-1+恢复减半+暴击-），通关返回 Hub 正常。
6. 切 MAGICIAN（先解锁 jack_frost）：牌库只发魔术师池；升到 Lv.3 火焰转 ALL。
7. 动画：手牌缩放、打出上飘、敌方突进+屏闪、HP 脉动、伤害染色。
8. 货币：战斗内 ¥ 起手 120 不带精魄；胜利奖励进 ◈；商店/升级扣 ◈。
